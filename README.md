# Симулятор Бомжа 3D

Небольшая мобильная 3D-игра на базе Three.js. Управление адаптировано под сенсорные устройства с двумя виртуальными стиками.

> ⚠️ Актуальная рабочая версия проекта хранится во ветке `game`. Убедитесь, что вы переключились на неё перед запуском или публикацией.

## Запуск локально

Откройте файл `index.html` в любом современном браузере. Для корректной работы модульных скриптов рекомендуется запускать через статический сервер, например:

```bash
npx serve .
```

Затем перейдите в браузере по адресу, который покажет сервер (обычно `http://localhost:3000`).

## Публикация на GitHub Pages

1. Создайте новый репозиторий и загрузите файлы проекта (`index.html`, `style.css`, `main.js`, `README.md`).
2. В настройках репозитория активируйте GitHub Pages и выберите ветку `main` (или вашу рабочую) с корневой директорией `/`.
3. Через несколько минут страница станет доступна по адресу `https://<ваш_логин>.github.io/<название_репозитория>/`.

## Игровой процесс

* Исследуйте процедурно сгенерированный район города.
* Собирайте мешки с едой, чтобы повышать голод, настроение и здоровье героя.
* Следите за полосками характеристик — если голод опустится до нуля, здоровье начнёт падать.
* При необходимости сворачивайте HUD кнопкой ⤢, чтобы освободить экран на телефоне.
* В центре района появились лавочки, фонари и озеленение — используйте их как ориентиры.
